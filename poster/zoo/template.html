Meet the models

They all do one job: look at a moment of a flight and output a correction to NAIRAS's estimate. dose = NAIRAS + correction. They differ only in how they read the last 24 hours of space weather.

Words used here, in plain English
Neuron
A tiny calculator: it adds up its inputs with weights and switches on if the total is big enough.
Layer
A row of neurons that all look at the same inputs. A network is layers in a stack.
MLP
Multi-Layer Perceptron: the simplest network, just stacked layers of neurons.
CNN
Convolutional Neural Network: slides a small filter along the data to find local patterns.
TCN
Temporal Convolutional Network: a CNN that skips hours so it can look far back in time.
Transformer
A network with attention: it learns which hours matter and mixes them with those weights.
Token
One hour of data (35 readings) treated as a single item.
Parameters
The numbers a network learns. More parameters can memorise more.
Overfitting
Memorising the training flights instead of learning something that works on new ones.

Run a model live

Pick a model and press Run. The network is computing in this page right now, so every colour and weight is real. Then edit its inputs and watch it respond.

Edits change what the networks receive; NAIRAS's own estimate stays fixed. Changing one input alone can make combinations that never happen in real flights, so read this as "what does the model respond to", not as a forecast. The Flat MLP and the MLP ignore the look-back edit by design.

Every model here is a single trained network (seed 42), run live in your browser from its real trained weights (checked against the original PyTorch outputs), on a flight it never saw during training. The flight is one example, not a benchmark: the 18-run results are in the report. Activations and attention show what a network computed, not physical cause.

Data: ARMAS and NAIRAS V3 machine-learning-ready data set (Sadykov et al., Space Weather 2026). Code: github.com/thesanjibkc/Deep_learning_project, branch final-project.
